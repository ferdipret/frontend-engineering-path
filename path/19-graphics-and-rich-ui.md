# Graphics, Visualisation, and Rich Interaction

> Stage: 3 · Advanced
> The specialised end of UI work: drawing, data visualisation, editors, and complex interactions. You don't need all of it, but a master can pick any of it up.

## SVG

- [ ] SVG fundamentals — shapes, paths, groups, `viewBox`, coordinate systems
- [ ] Styling and animating SVG — CSS, SMIL alternatives, stroke-dash techniques
- [ ] Accessible SVG — titles, roles, and hiding decorative graphics
- [ ] Optimising SVG — SVGO and sprite sheets

## Canvas and GPU

- [ ] Canvas 2D — drawing, transforms, the render loop, high-DPI scaling
- [ ] `OffscreenCanvas` — render in a worker
- [ ] WebGL basics — shaders, buffers, and the pipeline at a conceptual level
- [ ] Three.js — build and light a 3D scene
- [ ] WebGPU — know what it adds and when to reach for it
- [ ] Choosing a renderer — DOM vs SVG vs Canvas vs WebGL by element count and interactivity

## Data visualisation

- [ ] Chart selection — pick the right chart for the question
- [ ] Scales and axes — map data to pixels; use D3 scales and shapes
- [ ] A charting library — build with Recharts, visx, Observable Plot, or ECharts
- [ ] Interaction — tooltips, brushing, zoom, and linked views
- [ ] Accessible charts — text alternatives, keyboard access, colour-blind-safe palettes
- [ ] Large datasets — aggregation, canvas rendering, and downsampling
- [ ] Maps — render interactive maps with MapLibre GL, vector tiles, and data layers

## Complex interactions

- [ ] Drag and drop — pointer-based with keyboard support, or dnd-kit
- [ ] Gestures — pan, pinch, swipe with pointer events
- [ ] Virtualised lists and grids — variable-size rows and sticky headers
- [ ] Rich text editing — `contenteditable` pitfalls; ProseMirror, Lexical, or Tiptap
- [ ] Infinite canvas — pan/zoom transforms and hit testing
- [ ] Complex forms — dynamic fields, dependent validation, autosave

## Media

- [ ] Custom media players — the media element API and accessible controls
- [ ] Streaming — HLS and DASH basics; Media Source Extensions
- [ ] WebRTC — peer connections for video calls, at a working-knowledge level
- [ ] Web Audio — basic synthesis and analysis

## Projects

- [ ] Interactive dashboard — several linked charts over a real dataset
- [ ] Canvas app — a drawing tool or simple game with a proper render loop
- [ ] Kanban board — accessible drag and drop with keyboard reordering
